# WorkingOnCouchHH

**WorkingOnCouchHH** — это современное Android-приложение для поиска работы, разработанное в составе команды из 4 человек. Приложение предоставляет доступ к базе из миллионов вакансий с HeadHunter API и предлагает удобные инструменты для фильтрации, сохранения и просмотра вакансий без подключения к интернету.

---

## ✨ Ключевые особенности

*   **Обширная база вакансий**: Поиск по более чем миллиону актуальных вакансий с HeadHunter API.
*   **Умная фильтрация**: Гибкая система фильтров для точного поиска (специализация, зарплата, график и т.д.).
*   **Избранное**: Сохраняйте понравившиеся вакансии в избранное для быстрого доступа.
*   **Офлайн-режим**: Просматривайте свои избранные вакансии без подключения к интернету.
---

## 🛠 Технологический стек

Проект демонстрирует использование лучших практик в Android-разработке:

*   **Архитектурный паттерн**: **MVVM** для разделения логики.
*   **Асинхронность**: **Kotlin Coroutines** с **Flow** и **StateFlow** для реактивного и неблокирующего кода.
*   **DI (Внедрение зависимостей)**: **Koin** для простого и эффективного управления зависимостями.
*   **Сетевые запросы**: **Retrofit2** для REST-запросов к HH API.
*   **Локальная база данных**: **Room** для кэширования вакансий и работы в офлайн-режиме.
*   **Навигация**: **Jetpack Navigation Component** для простых и понятных переходах между экранами.

## 🏗️ Установка и запуск

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/KravtsovSO64/WorkingOnCouchHH
    ```
2.  Откройте проект в Android Studio.
3.  Получите API-ключ на сайте [HeadHunter API](https://dev.hh.ru/?ysclid=mfrbocnia5560714272).
4.  Не забудьте добавьте полученный ключ в проект.
5.  Приложение готово к запуску.
